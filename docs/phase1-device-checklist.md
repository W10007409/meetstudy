# 1단계 실기기 확인 목록 (학생 혼자 모드, Android)

1단계 앱은 단위 테스트 92개를 통과하고 빌드됩니다. 다만 사람 얼굴이나 실제 문제집이 있어야 확인할 수 있는 동작은 아직 기기에서 검증하지 않았습니다.

아래 항목은 갤럭시 탭 A8에서 직접 확인해야 합니다. 판정 기준값은 `logcat`에 찍힌 수치를 보고 정합니다.

## 준비
- 개발자 옵션에서 **애니메이션 배율을 1**로 바꿉니다. 0이면 거치 안내 애니메이션과 별 애니메이션이 멈춰 보입니다.
- 로그 보기: `adb logcat -s MeetStudyFace MeetStudyFrames MeetStudyProof`

## 확인 항목
1. **얼굴 등록**
   - "왼쪽으로 살짝", "오른쪽으로 살짝" 단계가 순서대로 넘어가는지 봅니다. 한 단계에서 계속 멈춰 있으면 좌우 각도 방향이 뒤집힌 것입니다.
2. **본인 판정 기준값**
   - 학생 본인의 `similarity=` 값을 여러 상황에서 기록합니다: 정면, 45도 거치, 문제집에서 고개를 드는 순간, 안경, 어두운 조명.
   - 다른 사람(형제나 부모)의 값도 같이 기록합니다.
   - 두 범위 사이의 값을 `IDENTITY_THRESHOLD`로 정합니다. 지금은 임시값 0.50입니다.
3. **고개 숙여 문제 풀기 (2분 이상)**
   - 얼굴이 보이는 상태로 필기하고, 얼굴이 가려진 상태로도 해봅니다.
   - '졸고 있어요', '다른 곳 보는 중', '자리 비움'이 뜨면 안 됩니다.
4. **빈 의자**
   - 자리를 비운 뒤 약 10초 안에 '자리 비움'이 되는지 봅니다. 빈 의자를 사람으로 잘못 감지하는지도 확인합니다.
5. **폰 오탐**
   - 책상 위에 폰(앞면과 뒷면), 계산기, 필통을 두고 10초 안에 '폰 사용 중'이 뜨는지 봅니다.
   - 실제로 폰을 들고 사용했을 때는 '폰 사용 중'이 떠야 합니다.
6. **장시간 사용 (30~60분)**
   - 발열 때문에 `phone detection disabled`가 찍히는지 봅니다. 감지 속도 기준은 평균 150ms 이하입니다.
7. **앱 나갔다 오기**
   - 홈 버튼, 전원 버튼, 오래 나가 있기를 각각 해봅니다.
   - 돌아오면 카메라가 다시 붙고 '앱 나감'에서 '공부 중'으로 바뀌어야 합니다. 다시 캘리브레이션하지 않아야 합니다.
8. **휴식 초과, 목표 달성, 카메라 가림**
   - 휴식 10분을 넘기면 '자리 비움'으로 바뀌는지 봅니다.
   - 목표 시간을 채우면 자동으로 종료되는지 봅니다.
   - 카메라를 가리면 빨간 "카메라를 확인해 주세요" 배너가 뜨는지 봅니다.
9. **문제집 인증**
   - 실제 문제집을 비추면 테두리가 초록색으로 바뀌고 1초 뒤 자동 촬영되는지 봅니다.
   - 빈 A4 용지와 얼굴로는 촬영되지 않아야 합니다.
   - 45도로 기울인 페이지와 작은 글씨도 해봅니다.
   - 공유 카드를 카카오톡으로 받았을 때 1080×1350 이미지로 오는지 봅니다.
10. **리포트**
    - 이벤트 시각이 현지 시간으로 나오는지 봅니다.
    - 주간·월간 별 개수와 연속 달성일이 실제로 받은 것과 같은지 봅니다.

## 알려진 한계 (의도적으로 남겨 둔 것)
- **고개 각도 경계**: 고개를 정확히 ±35° 경계에서 15초 이상 유지하면 '다른 곳 보는 중'이 될 수 있습니다. 3번 확인에서 문제가 되면 판정에 여유 구간(히스테리시스)을 추가합니다.
- **폰 감지 범위**: 폰이 손 근처에 있는지는 확인하지 않습니다. 5번 확인에서 오탐이 많으면 손 위치 확인을 추가합니다.
- **인증 우회**: 글자가 떠 있는 모니터 화면, 또는 글자가 많은 아무 인쇄물(가까이 찍어 테두리가 안 보일 때)도 문제집 인증을 통과할 수 있습니다. 검사를 기기에서만 하는 MVP의 한계입니다.
- **전화 사유**: 전화가 와서 앱을 나간 경우도 '앱 나감'으로 기록됩니다. '전화' 사유는 따로 구분하지 않습니다.
- **출시 전 필수**: 만 14세 미만 법정대리인 동의, 얼굴 비교 모델(MobileFaceNet) 학습 데이터의 법무 검토, OpenCV의 16KB 페이지 정렬 확인
